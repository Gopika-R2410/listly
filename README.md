# ✨ Checklist App

A modern, lightning-fast, and minimalist **Task Management & Checklist Web Application** designed for daily productivity. Built with pure HTML5, modern CSS, and vanilla JavaScript.

[🚀 View Live Demo](https://listly-lemon.vercel.app/) · [🐛 Report Bug](https://github.com/Gopika-R2410/listly/issues) · [✨ Request Feature](../../issues)

</div>

---

## 🎨 Theme & Design
- **Color Palette:** Rich Royal Blue paired with Warm Yellow shades.
- **Responsive:** Fully optimized for desktop, tablet, and mobile screens.
- **Local Persistence:** Secure real-time session tracking and state storage.

---

## 🚀 Key Features

- **🔐 Real-time Authentication:** Secure login & signup flow to manage personal data.
- **📋 Checklist Management:** Create, edit, rename, and delete custom checklists on the fly.
- **⚡ Dynamic Task Control:** Add, check off, and remove tasks with fluid micro-interactions.
- **🌙 Clean UI/UX:** Clutter-free design with no unnecessary tags or heavy frameworks.

---

## 🛠️ Built With

* **HTML5** - Semantic layout and structure
* **CSS3 / Tailwind-inspired Design** - Custom responsive styling and flexbox/grid
* **JavaScript (ES6+)** - Interactive DOM manipulation and state management
